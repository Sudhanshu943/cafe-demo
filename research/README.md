# Café website research collection

Research date: 5 November 2026. Scope: research and resource collection, before website planning or implementation.

## Read in this order

**Expanded collection:** [Seven separate design directions](design-directions/README.md), each with a brief, reference resources and an original visual board. Start here when comparing options with a client.

1. [Research report](01-research-report.md): direction, current references, UX, navigation, section design, typography and color.
2. [Motion and 3D catalogue](02-motion-and-3d.md): effects, timings, scrolling, 3D asset concepts and fallback behavior.
3. [Libraries and asset resources](03-libraries-and-assets.md): technology comparisons, acquisition links and asset briefs.
4. [Source register](04-sources.md): dated evidence, direct URLs, access limits and further-review references.
5. [Decisions for the planning phase](05-planning-inputs.md): unresolved brand and business choices; no implementation schedule.

## Main recommendation

Explore a warm editorial café identity with cream backgrounds, espresso typography, a forest-green action color, genuine venue photography and one signature 3D cup scene. Keep menu, prices, hours and directions immediately accessible. This is a proposed direction, not an approved design.

## What has actually been collected

Original research notes, linked internet references, a library comparison, visual specifications, an effects catalogue and proposed asset briefs. No third-party photography, models, fonts or competitor artwork have been downloaded or licensed. No packages have been installed and no website has been built.

Sources were reviewed through web search and extracted page content. This establishes content and documented capabilities, but does not verify rendered layouts, live animation behavior, mobile usability or loading speed. Competitor visual direction and motion still need a browser-based review during design exploration. This is a focused reference sample, not a comprehensive survey of every café website.
